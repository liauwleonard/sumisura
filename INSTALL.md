# Sumisura — Cara Pasang · How to Install

*Sumisura* — dari bahasa Italia **su misura**: dijahit sesuai ukuran.
*Italian for "made to measure".*

Buka tautan ini di perangkat Anda, lalu ikuti langkah untuk perangkat itu.
*Open this link on your device, then follow the steps for that device.*

> **https://liauwleonard.github.io/sumisura/**
> 

Aplikasi ini gratis, tidak perlu App Store, dan **bisa dipakai tanpa internet** setelah dipasang.
*Free, no App Store needed, and works without internet once installed.*

---

## iPad / iPhone (Safari)

Harus pakai **Safari**. Chrome di iPhone tidak bisa memasang aplikasi.
*Must use Safari — Chrome on iPhone cannot install it.*

1. Buka tautan di atas di **Safari**.
2. Ketuk tombol **Bagikan** (kotak dengan panah ke atas ⬆️) di bawah layar (iPhone) atau di atas (iPad).
3. Gulir ke bawah, ketuk **Tambahkan ke Layar Utama** / **Add to Home Screen**.
4. Ketuk **Tambah** / **Add** di pojok kanan atas.

Ikon **Sumisura** sekarang ada di layar utama. Buka dari situ — bukan dari Safari lagi.
*The Sumisura icon is now on the home screen. Open it from there, not from Safari.*

---

## MacBook (Safari)

1. Buka tautan di atas di **Safari**.
2. Di menu atas, pilih **File → Add to Dock…**
3. Klik **Add**.

Aplikasi muncul di Dock dan Launchpad seperti aplikasi biasa.
*The app appears in the Dock and Launchpad like a normal app.*

### MacBook (Chrome / Edge)

1. Buka tautan di atas.
2. Klik ikon **pasang** (layar kecil dengan panah ⤓) di ujung kanan kolom alamat.
3. Klik **Install**.

---

## Sesudah dipasang · After installing

- **Ganti bahasa:** ketuk **Pengaturan → Bahasa**.
- **Ganti satuan:** cm atau inci, juga di **Pengaturan**.
- **Tanpa internet:** aplikasi tetap jalan. Semua data tersimpan di perangkat.

---

## ⚠️ Penting — data masih tersimpan di perangkat ini saja

*Important — for now, data lives only on this one device.*

Sampai fitur sinkronisasi selesai (Tahap 3):

- Data **tidak** berpindah antar iPad, iPhone, dan MacBook. Tiap perangkat punya catatan sendiri.
- Jika riwayat browser (Safari) dihapus, **data bisa ikut terhapus**.
- Karena itu: **pakai satu perangkat saja dulu** — sebaiknya iPad — sampai sinkronisasi aktif.

*Until sync ships (Phase 3): data does not move between devices, and clearing Safari's website
data can erase it. Use one device only — ideally the iPad — until sync is live.*

---

## Memperbarui aplikasi · Updating

Kalau ada versi baru, muncul kotak kecil di bawah layar: **"Versi baru sudah siap"**.

1. **Simpan** dulu pekerjaan yang sedang dibuka.
2. Baru ketuk **Perbarui sekarang**.

Aplikasi tidak akan memperbarui sendiri saat Anda sedang mengukur.
*The app never updates itself while you are mid-measurement.*
