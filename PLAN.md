# Plan — sumisura

Roadmap and status. Work one phase/slice at a time; review before moving on.

## Goal
The tailor runs his shop from this app instead of his notebook. Installed on his iPad, MacBook,
and iPhone, all three in sync. He can open any past order and see exactly what it was cut from.
If the app is shared with another tailor, neither can see the other's data.

## Status
Phase 2 built and verified locally (2026-08-16). **Not yet deployed** — no GitHub repo exists yet,
which is the only remaining Phase 2 step.

---

## Phase 1 — Local app (no login, no cloud) ✅
Target: a genuinely usable tool on one device.

- [x] Vite + React + TS + Tailwind project setup
- [x] Dexie schema: shops, customers, orders, measurements, material, cut_style, payments, change_log
- [x] Orders list (home) — active, due dates, overdue, receivables filter
- [x] New order step 1: customer **search-or-create** (live search, phone dedup check)
- [x] Measurement screen — fields by garment group, cm/inch toggle, posture notes
- [x] **SVG mannequin** — arms out / legs apart, front + back views, lines filtered by active group,
      two-way tap-to-focus between figure and fields
- [x] Prefill from latest order (measurements + cut style) with `from order #N · date` tags and a
      "Measure fresh" button
- [x] Material: fabric, color, meters, lining, notes
- [x] Cut style: per-garment dropdowns + "Other →" free text
- [x] Multiple items per order (jacket + trousers + waistcoat), one measurement set, one balance
- [x] Balance: total, deposit(s), auto receivable, status
- [x] **Change log** — every edit recorded; dot indicator on edited fields, tap for history
- [x] Order status flow: Measured → Cutting → Fitting → Finishing → Ready → Collected

Bilingual EN/ID dictionaries and the cm/inch toggle landed early rather than in Phase 4 — field
labels had to come from the dictionary anyway to keep stored keys renameable.

### Deliberately not in Phase 1
- Customers screen (browse/search customers outside an order) — next slice
- Delete an order (soft-delete exists in the schema, no UI yet)
- Merge duplicate customers — Phase 4
